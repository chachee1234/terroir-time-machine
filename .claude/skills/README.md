# Project skills

Claude sessions that open this repo load these skills automatically. They are copied from
[ECC](https://github.com/affaan-m/ECC) (commit c70874f, v2.2.2, MIT license, see LICENSE-ECC), with a
"Terroir Time Machine notes" section added at the end of each. Only these four were taken; ECC's
hooks, agents, commands and memory system are deliberately not installed (see
tooling/ecc-analysis.md in the project files for why).

| Skill | Use it for |
|---|---|
| verification-loop | Checking work before opening a PR |
| browser-qa | Loading the viewer headless and catching console errors |
| search-first | Looking for existing datasets and tools before writing new scripts |
| scientific-thinking-literature-review | Sourcing geology, soil and climate claims |
