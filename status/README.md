# Progress notes

One file per change, named `<YYYY-MM-DD>-<branch>.md` (for example `2026-10-07-autopilot.md`). Write a new file instead of appending to `STATUS.md`: when several pull requests are open, they all appended to the end of `STATUS.md`, so every merge made the others conflict at the same lines. Separate files never clash.

Each note keeps the old entry format: a `##` heading with what changed and the date, then what was done, the exact commands run with their results, anything not tested, and the next smallest action. If a branch needs a second note on the same day, add `-2` to the name.

Read the newest files here, after `STATUS.md`, to see the current state.
